Метро New International — Новостной портал

Новостной сайт проекта Метро New. Публикация мировых новостей, технологий, культуры, спорта и погоды. Минималистичный дизайн, автопубликация в Telegram и Discord, тёмная тема.

Сайт

URL: https://kirill12633.github.io/press.metro.new/

Возможности

    Новости — мировые события, технологии, культура, спорт, погода

    LIVE — прямые трансляции с таймлайном

    Вертикали — короткие вертикальные видео

    Репортажи — видеоматериалы и обзоры

    Поиск — по заголовкам и тексту

    Тёмная тема — prefers-color-scheme + ручной переключатель

    Адаптив — телефон, планшет, десктоп

    PWA — можно установить как приложение
